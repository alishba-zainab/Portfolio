# Alishba Zainab - Portfolio

This is my personal portfolio website. Built using plain HTML, CSS, and JavaScript — no React, no Tailwind, no build tools. 

## What's used

- HTML for the page structure (index.html)
- CSS for styling and layout (css/style.css)
- JavaScript for nav behavior, scroll animations, and the contact form (js/script.js)
- Google Fonts (Fraunces, Inter, IBM Plex Mono)

## Design

Dark navy background with a grid pattern in the back, like blueprint/drafting paper. Amber/orange used as the accent color, and project cards use a lighter paper-like color for contrast. Fraunces font for headings, Inter for body text, IBM Plex Mono for labels and tags.

Some animations used:
- Scrolling skill chips in the hero section
- Sections fade in as you scroll down
- A small spinning dot animation near the contact section
- Project cards zoom slightly on hover
- Nav links, skill chips, and certification rows have hover effects

## Running it locally

Just open index.html in a browser. Or use the Live Server extension in VS Code for auto-refresh while editing.
